# RadioML Modulation Classification ML Pipeline

This directory contains the machine learning pipeline for automatic modulation classification (AMC) trained on the **RadioML 2016.10A** synthetic dataset.

> **IMPORTANT DISCLAIMER**:
> RadioML 2016.10A is an open synthetic benchmark dataset generated using GNU Radio. It does **NOT** represent restricted NTRO operational data or real-world classified intelligence signals.

---

## 1. Dataset Location

Expected dataset filepath:
`datasets/radioml/RML2016.10a/RML2016.10a_dict.pkl` (or `RML2016.10a_dict_optimized.pkl`).

Dataset structure:
- Python dictionary mapping `(modulation_name, snr_dB)` tuples to NumPy arrays of shape `(1000, 2, 128)` float32.
- **Modulation Classes (11)**: 8PSK, AM-DSB, AM-SSB, BPSK, CPFSK, GFSK, PAM4, QAM16, QAM64, QPSK, WBFM.
- **SNR Range (20)**: -20 dB to +18 dB (in 2 dB steps).

---

## 2. How to Train

To train the Random Forest modulation classifier:

```bash
# Run with default configurable limit (MAX_SAMPLES_PER_CLASS_SNR = 1000)
python -m ml.train_modulation_model

# Run with custom limit (e.g. 500 samples per class/SNR for faster iteration)
python -m ml.train_modulation_model --max_samples 500

# Run on the full dataset (all 220,000 samples)
python -m ml.train_modulation_model --max_samples 0
```

### Outputs Generated by Training:
- `models/radioml_modulation_model.joblib`: Serialized RandomForestClassifier model & StandardScaler pipeline artifact.
- `models/modulation_classes.json`: List of trained modulation class labels.
- `ml/results/test_set.joblib`: Held-out test set samples, labels, and SNR annotations for evaluation.

---

## 3. How to Evaluate

To evaluate the trained model on the held-out test dataset:

```bash
python -m ml.evaluate_model
```

### Outputs Generated by Evaluation:
- `ml/results/classification_report.txt`: Full text report containing Precision, Recall, F1-score per class.
- `ml/results/metrics.json`: Machine-readable summary of overall accuracy, weighted/macro F1 scores, and Accuracy-vs-SNR map.
- `ml/results/confusion_matrix.png`: Plotted confusion matrix visualization.
- `ml/results/accuracy_vs_snr.png`: Graph of classification accuracy vs. SNR (-20 dB to +18 dB).

---

## 4. How to Make a Prediction

In Python code, use the reusable prediction function `predict_modulation`:

```python
import numpy as np
from ml.predict import predict_modulation

# Generate or load IQ sample array (shape (2, 128) or 1D complex)
iq_data = np.random.randn(2, 128)

# Predict modulation
result = predict_modulation(iq_data, sample_rate=48000)

print("Predicted Modulation:", result["modulation"])
print("Confidence          :", result["confidence"], "%")
print("Method              :", result["classification_method"])  # "ML" or "HEURISTIC"
print("Model Name          :", result["model_name"])
```

If the model file `models/radioml_modulation_model.joblib` is present, `predict_modulation` uses the real ML model. If the file is missing, it gracefully falls back to the statistical heuristic classifier.

---

## 5. What the Metrics Mean

- **Accuracy**: Percentage of test IQ frames correctly classified into their ground-truth modulation format.
- **Precision**: Proportion of signals classified as modulation $M$ that were truly modulation $M$.
- **Recall**: Proportion of true modulation $M$ signals that were correctly identified by the model.
- **F1-Score**: Harmonic mean of Precision and Recall ($2 \times \frac{P \times R}{P + R}$).
- **Accuracy by SNR**: Measures classification performance across noise levels. Higher SNRs (> 0 dB) typically exhibit significantly higher accuracy than low SNRs (-20 dB to -6 dB) where noise dominates the signal.
